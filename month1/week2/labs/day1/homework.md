## Question 1
What is a Boolean?
Answer: A boolean is a dataype that returns True or False.

# Question 2
What's the difference between = and ==?
Answer: = is an assignment operator and == is a comparison operator

# Question 3
How does an if statement work?
Answer: An if statements evaluates a condition(an expression that results in True or False), if the condtion is met, the code block in the IF statement is executed, if the condition is False, the code block is skipped

# Question 4
Why does Python use indentation?
Answer: Indentation is used to organise and group statements into blocks of code

# Question 5
When would you use elif instead of another if?
Answer: elif is used when there is a mutually exclusive condition where only one block of code should execute.
