# Homework Day 5

## Question 1
What is a function?
Answer: A function is a named, reusable unit of behavior that performs a specific task.

## Question 2
Why do engineers use functions?
Answer: Engineers use functions so as not to repeat codes. They can write a function that performs a specific task and just call that function as many times as they like when they need it instead of repeating code over and over again. Functions are preferred for:
- Reusability
- Readability
- Maintainability
- Testability
- Separation of concerns

## Question 3
What's the difference between a parameter and an argument?
Answer: A parameter is what you pass to the function when the function is being defined and arguments are what you pass to the function when the function is being called.

## Question 4
What's the difference between print() and return?
Answer: The difference between print() and return is that return can be reused and returning is for programs while print() is for humans.

## Question 5
Why is return usually preferred inside reusable functions?
Answer: return is preferred because it gives the calling code access to the computed value, allowing that value to be stored, combined with other computations, or used in further logic.
